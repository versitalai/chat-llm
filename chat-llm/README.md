# Chat-LLM
A custom Large Language Model project optimized for casual, natural chatting.

## Goal
The primary objective of this project is to develop an LLM that excels in casual conversation, focusing on personality, fluid dialogue, and human-like interaction rather than raw information retrieval or "assistant-style" task completion.

## Project Structure
- `src/`: Source code
    - `training/`: Data preprocessing and training scripts
    - `inference/`: Model loading and chat interface
    - `eval/`: Evaluation metrics for chat quality
- `data/`: Datasets
    - `raw/`: Original dialogue datasets
    - `processed/`: Cleaned and tokenized data
- `configs/`: Model and training configurations
- `docs/`: Design documents and research
- `tests/`: Unit and integration tests
